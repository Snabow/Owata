## Trust boundary

Real Reviewer:

- receives exact `target_sha`
- fresh disposable worktree (not Builder writable worktree)
- no Builder chat/history
- no source write authority (fail-closed immutability gate)
- returns PASS / REWORK / BLOCK + findings
- leaves Program Control as sole adjudicator

## Canary contract

`npm run canary:b2-reviewer`:

1. disposable task repo with `ACCEPTANCE.md` expecting `STATUS=READY`
2. intentionally failing candidate `STATUS=BROKEN`
3. canonical REVIEW for exact candidate SHA
4. real Codex invocation **once**
5. expect verdict `REWORK` with ≥1 finding
6. candidate unchanged; workspace clean; **workspace removed** with retained `workspace-cleanup-proof.json`
7. cycle stops at `AWAITING_PC` (`human_continuity_actions=0`)

Cleanup failure is fail-closed: reviewer_result is **not** accepted as workflow authority if disposable workspace cleanup/verification fails.

Normal `npm test` does not invoke Codex or any external model.

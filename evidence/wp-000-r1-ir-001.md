# WP-000 REWORK R1 Evidence — WP000-IR-001

Recorded: 2026-08-29

## Finding

`WP000-IR-001` — `owata doctor` treated an existing regular file at the state-directory path as PASS.

## Change

`ensureStateDirectory` now verifies the filesystem object is a directory via `statSync(...).isDirectory()`.

Existing non-directory → FAIL / exit `1`.

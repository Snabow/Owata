## F001 repair (OWATA-REQ-0139)

**Finding:** OWATA-REQ-0138-F001 — after successful NEW initial claim, dispatcher wrote CLAIMED + `cycle.dispatch_claimed` then separately appended `cycle.routing_selected`. Crash between them left attribution without routing evidence (A-034 violation).

**Repair:** Extend `HandoffStore.claimDispatch({ coupledEvent? })` so optional claim-coupled event insert runs inside the same `ControlStore.runImmediate()` success transaction as INSERT dispatch CLAIMED, optional prior-CLAIMED recovery, and `cycle.dispatch_claimed`. Dispatcher passes `cycle.routing_selected` as `coupledEvent` and no longer appends it post-claim. `RETRY_BUDGET` / `enterRecovery` remain outside the success transaction.

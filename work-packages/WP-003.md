## Objective

Remove **Human Clipboard** from one complete Program Control → Builder → Independent Reviewer → Program Control cycle.

OWATA must persist structured handoffs, dispatch them through a deterministic Core, and resume after session loss, process interruption, or provider replacement — without Human copy/paste, manual agent invocation, manual role routing, or manual session switching.

Human involvement is allowed only at an intentional Human Gate.

---

## Why WP-003 exists

WP-002 completed the single-worker completion loop: a durable Control Core can take one queued work item from claim through verified COMPLETED (or classified FAILED) without Human intervention.

The remaining Genesis bottleneck is not local work execution. It is that Humans still operate as the message bus between logical roles:

```text
Program Control
↓ Human copy/paste + session switch
Builder
↓ Human copy/paste + session switch
Independent Reviewer
↓ Human copy/paste + session switch
Program Control
```

Charter Phase 3 success condition:

> Builder and Reviewer are separated by formal artifacts only, and REWORK returns to Builder automatically.

WP-003 is that phase, scoped to the smallest local implementation that proves OWATA semantics.

---

## Problem statement — Human Clipboard

Human currently:

- copies Work Packages and results between agents
- starts the next agent by hand
- chooses which session or product to open
- remembers where the cycle is
- routes REWORK back to Builder

That is operator work, not approval work. WP-003 must take it.

## Dispatcher boundary

Introduce a deterministic Dispatcher inside OWATA Core.

The Dispatcher may:

- persist validated envelopes
- inspect deterministic state
- execute predefined transitions
- perform capability preflight
- invoke configured adapters
- enforce leases / fencing / idempotency / retry budgets
- capture results
- resume interrupted work

The Dispatcher MUST NOT:

- originate Program Control decisions
- adjudicate Reviewer findings
- decide REWORK scope
- approve Builder output
- suppress or rewrite Reviewer findings
- silently change project architecture
- choose Human-impacting outcomes

Meaningful next-action decisions remain Program Control authority.

Automatic Builder-candidate → Reviewer dispatch is allowed only as execution of previously durable Program Control policy/decision. The Dispatcher does not independently decide that review should occur.

## Capability / resource contract

WP-003 introduces the minimum preflight needed to avoid assigning work to an incapable runtime.

The first protocol should be able to express requirements such as:

- `repository_read`
- `repository_write`
- `exact_checkout`
- `command_execution`
- `dependency_install` where applicable
- `network` access where applicable

Classify failure before execution where possible, for example:

- `CAPABILITY_BLOCK`
- `AGENT_UNAVAILABLE`
- `REPO_UNAVAILABLE`
- `CREDENTIAL_UNAVAILABLE`
- `RUNTIME_ERROR`
- `RESULT_INVALID`
- `RESULT_STALE`
- product / work failure

Do not implement generalized provider routing in WP-003.

## Failure semantics

Genesis Charter remains authoritative: **Failure is State, not Terminal.**

Do not define “rework budget exhausted → terminal FAILED” automatically.

When bounded automatic recovery is exhausted, control returns to Program Control.

Program Control may then choose, according to current capabilities:

- RETRY
- bounded REWORK
- REDESIGN
- change runtime / provider when available
- HUMAN_GATE
- ABORT

Terminal project / work failure requires an explicit semantic terminal decision such as Program Control ABORT, not merely exhaustion of an arbitrary retry counter.

This does not rewrite WP-002’s local worker-loop `FAILED` contract for deterministic proving samples. WP-003 governs the structured-handoff cycle, not `sum_two` attempt terminalization.

## Human Gate semantics

- credentials the agent cannot obtain
- irreversible or externally binding approval

- cost / safety / legal constraints

Human Clipboard (copy/paste, manual invocation, manual routing, session switching) is not a Human Gate.
